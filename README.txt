DEEPIKA'S LIGHT-THEME PORTFOLIO
================================

HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or double-click index.html.

CUSTOMIZE BEFORE PUBLISHING
1. In index.html, replace YOUR_EMAIL@example.com with your email address.
2. Replace LinkedIn and GitHub placeholder URLs with your real profile URLs.
3. Replace project repository placeholders with the correct repository links.
4. Verify internship dates and descriptions.
5. Add a real resume PDF link if you want a downloadable resume.

FILES
- index.html : portfolio content
- style.css  : light professional theme and responsive layout
- script.js  : mobile navigation interaction

DEPLOYMENT
Push the folder to GitHub, then publish with GitHub Pages or import the repository into Vercel.
